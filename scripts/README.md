# Historical script archive

The numbered directories in `scripts/` are the original repository snapshot.
They are retained so readers can trace how historical objects and figures were
created. They are **not** the authoritative workflow for the revised manuscript.

Known boundaries include historical absolute/implicit working-directory
assumptions, an apparent rather than fully nested model-development estimate,
ICGC having been consulted during historical model selection, unvalidated
CellChat/virtual-knockout evidence, and a pathology workflow that required
corrected patient-level reassessment.

Use the corresponding module under `revision/` whenever one exists. Do not
silently combine historical and revised outputs; the figure crosswalk in
`docs/FIGURE_CODE_MAP.md` identifies the current source for each claim.
