# HCC Oxidative Stress Multi-Omics Code

This repository contains analysis scripts for an HCC oxidative-stress prognostic model and multi-omics integration study.

The code is organized as a reproducible script archive for manuscript review. Large intermediate objects, raw data, clinical matrices, model result files, figures, and logs are intentionally not tracked in git.

## Included Modules

- `scripts/01_scRNA_oxidative_stress/`: single-cell preprocessing, oxidative-stress scoring, epithelial/tumor-cell extraction, CNV calling, NMF programs, Scissor survival association, and GO/KEGG analysis.
- `scripts/02_cell_subtyping/`: subdivision of NK/T, macrophage, B, DC, CAF, endothelial, neutrophil, CD8 Trm, and cytotoxic CD4 compartments.
- `scripts/03_annotation_integration/`: subtype integration, rare-subtype filtering, QC checks, and final integrated Seurat object visualization.
- `scripts/04_spatial_transcriptomics/`: spatial oxidative-stress scoring and RCTD spatial deconvolution.
- `scripts/05_bulk_deconvolution/`: BayesPrism TCGA-LIHC bulk RNA-seq deconvolution and survival-linked cell-fraction analysis.
- `scripts/06_prognostic_modeling/`: TCGA/ICGC oxidative-stress prognostic modeling with `Mime1`, model visualization, and StepCox+GBM risk-model extraction.
- `scripts/07_wsi_pathology/`: ResNet50 WSI feature aggregation, correlation with transcriptomic risk score, and pathology-feature prognostic modeling.
- `scripts/08_functional_analysis/`: tumor functional analysis, CellChat communication analysis, macrophage-tumor communication, and NQO1 virtual knockout.

## Not Included

The current working directory did not contain publishable code for these manuscript sections, so no placeholder scripts were added:

- CT radiomics
- CMAP drug prediction
- Molecular docking

Add those modules only when the real scripts are available.

## Expected Inputs

Place external data and generated intermediate objects in the repository root, or update script paths consistently before running. Typical required inputs include:

- `data/03注释.Rdata`: initial annotated single-cell Seurat object used by `00重分.R`.
- `data/02fastcnvST.Rdata`: spatial object for ST oxidative-stress scoring.
- `sceall.Rdata`, `02ep.Rdata`, `03epcnv.Rdata`, `03tc.Rdata`, `tcos.Rdata`, `05osnmf.Rdata`, `注释sceall.Rdata`: intermediate Seurat objects generated by earlier scripts.
- `bulk/TCGA-LIHC.Rdata`, `bulk/exp1surv1.rdata`, `bulk/TCGA临床信息.txt`: bulk RNA-seq and survival/clinical inputs.
- `QWEN0208.Rdata`: TCGA/ICGC/GSE expression-survival list and candidate genes for prognostic model building.
- `res_no_GSE14520.Rdata` or `res_fixed.Rdata`: saved `Mime1` model results for downstream visualization/extraction.
- `resnet50_features.csv`: tile-level WSI ResNet50 feature matrix.
- `visium_ST_processed.RData`: processed Visium spatial transcriptomics object.

These files are excluded by `.gitignore` because they are large generated or controlled-access data objects.

## Suggested Run Order

Run scripts from the repository root so relative paths resolve as expected.

```bash
Rscript scripts/01_scRNA_oxidative_stress/00重分.R
Rscript scripts/01_scRNA_oxidative_stress/01氧化应激分析.R
Rscript scripts/01_scRNA_oxidative_stress/02提取上皮细胞细分.R
Rscript scripts/01_scRNA_oxidative_stress/03fastcnv.R
Rscript scripts/01_scRNA_oxidative_stress/04氧化应激.R
Rscript scripts/01_scRNA_oxidative_stress/05osnmf.R
Rscript scripts/01_scRNA_oxidative_stress/06差异分析和生物学功能.R
```

Cell-subtyping scripts can then be run by module number, followed by integration scripts:

```bash
Rscript scripts/02_cell_subtyping/07_NKT_subdivision.R
Rscript scripts/02_cell_subtyping/08_Mac_subdivision.R
Rscript scripts/02_cell_subtyping/09_B_subdivision.R
Rscript scripts/02_cell_subtyping/10_DC_subdivision.R
Rscript scripts/02_cell_subtyping/11_CAF_subdivision.R
Rscript scripts/02_cell_subtyping/12_Endo_subdivision.R
Rscript scripts/02_cell_subtyping/13_Neu_subdivision.R
Rscript scripts/03_annotation_integration/19_integrate_all_cells.R
```

Run downstream modules only after their required `.Rdata` or matrix inputs exist.

## Repository Hygiene

The `.gitignore` excludes:

- raw and intermediate omics objects (`*.Rdata`, `*.RData`, `*.rds`, `*.h5ad`, etc.)
- tabular generated outputs (`*.csv`, `*.tsv`, `*.xlsx`)
- generated figures (`*.pdf`, `*.png`, etc.)
- logs and PID files
- model outputs and temporary results

This keeps the GitHub repository focused on real code only.
